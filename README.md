# Coding 1: In-class assignment 2

You have ten minutes. Fork this repository to your own GitHub account.

## Task

In `assignment.py`, add short comments explaining each line or block. Before running it, write a comment predicting the two values that will be printed and commit that prediction. Then run the script, correct any wrong prediction in a second commit, and push both commits to your fork.

Do not change the Python code.

## Marking

- **2**: comments explain the data structures and operations.
- **1**: comments merely restate the syntax.
- **0**: no timely commit or no substantive comments.

AI tools are not allowed in Coding 1.
